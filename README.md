## About this portfolio

The portfolio is designed to show more than a list of tools. Each case study focuses on:

- the problem or assignment context,
- the approach and tools used,
- the technical or communication skills demonstrated,
- the evidence or project output,
- and the lessons or outcomes gained from the work.

The site includes academic coursework, professional experience, enterprise work, technical labs, documentation, presentations, and selected community/service projects.

## Run locally

### Requirements

- Node.js 20+
- npm

### Setup

```bash
git clone https://github.com/Edward-Wonder-Mordey/portfolio.git
cd portfolio
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

---

## Deployment

The site deploys automatically to **GitHub Pages** through GitHub Actions whenever changes are pushed to the `main` branch.

The workflow:

1. checks out the repository,
2. installs dependencies with `npm ci`,
3. builds the Vite project,
4. uploads the `dist` output,
5. deploys the build to GitHub Pages.
